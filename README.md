# Portfolio - Nardine (Project Manager & Event Specialist)

هذا هو الـ Portfolio الخاص بي جاهز للرفع المباشر على **GitHub Pages**.

## 📁 هيكل المجلدات (Directory Structure)
- `index.html`: الصفحة الرئيسية للموقع.
- `css/style.css`: ملف التنسيقات والتصميم كامل.
- `js/main.js`: ملف التفاعلات والروابط.
- `assets/images/`: مجلد لوضع صور الفعاليات أو الصورة الشخصية.
- `assets/docs/`: مجلد لوضع ملف السيرة الذاتية (CV).
